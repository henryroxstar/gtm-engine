# Call-Prep Brief Template

Use this structure when outputting `call-prep-[company]-[YYYY-MM-DD].md`.
Replace all `{…}` placeholders with real content; delete any section the colleague said to skip.

This is the **shape** only — what belongs in each section is in the skill body's *Build the brief*,
and the two are meant to agree. A column here that the body does not ask for (or a rule the body
added that never reached this file) is drift, and it is the reason this file has to stay cited.
