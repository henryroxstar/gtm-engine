# tests/lint/retired_patch_paths.txt — dotted paths a module split has RETIRED (docs/RULES.md §R10).
#
# After `old_module.py` becomes the package `old_module/`, its `__init__` re-exports every name,
# so `from old_module import f` keeps working — but a test that does
# `patch("old_module.f")` now patches the re-export binding, while the moved code binds `f` in
# its own submodule. The mock silently stops intercepting; the real code runs; CI stays green.
#
# Every split PR appends the paths it retired. The check (tests/lint/complexity_check.py, run
# at pre-commit and under pytest) fails any `patch(...)` / `monkeypatch.setattr(...)` string in
# tests/ that names one — and any `patch.object(<module alias>, "name")` /
# `monkeypatch.setattr(<module alias>, "name", …)` / `patch.multiple(…)` that resolves to one
# through the file's imports. Re-point such a patch at the module where the moved code USES
# the name.
#
# One dotted path per line. Phase 0 froze an empty list; each split appends a dated block.
